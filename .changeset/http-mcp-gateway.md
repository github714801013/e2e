Add `e2e mcp --http`: a Streamable HTTP gateway with Bearer tokens, MCP sessions bound to the token that opened them, Host and Origin allowlists, request body limits, an idle session TTL, and `/healthz`. Each MCP session reuses its own `e2e mcp` child, and a token may limit which tools it calls. The gateway also serves `list_test_scripts`, `get_test_script`, and `save_test_script`, confined to `.e2e.ts` files under `--test-root`, with atomic saves and collection in a child process; a failed collection reports the exit status only, never the project's stderr.

The gateway has no global session cap. A session that opens a target counts against its principal's `--max-sessions-per-domain` quota (default 20, 1 through 100) for that target's app URL host, or its target name when it declares no URL; opening past the limit reclaims the least recently active session of that group. `open_session` results carry structured content naming the `target`, its `platform`, and its `appUrl`. `--max-sessions` still bounds native sessions over stdio and is refused together with `--http`.

It also serves `run_test`, `get_test_status`, and `get_test_report`: a job is written to `.e2e/http-jobs/` before a forked Runner collects and runs the submitted files, survives the connection that queued it, and is readable only by the principal that submitted it, so a token that grants a job tool must name one. Submissions for one target join its current run, whose authentication setup runs once; a repeated file gets its own result. Workers start on demand and never past `--max-workers` (default 4). `--max-runs` (default 2) bounds concurrent runs, one run holds at most 20 unfinished jobs, and a submission past either limit returns `CAPACITY_EXCEEDED`. Idle runs seal, a job has fifteen minutes from submission, a run has thirty, and a job or run that outlives its deadline is reported as timed out. A submission after a run sealed waits for that child to exit before starting the successor, so one target never runs two logins. A failing teardown hook also fails a job that already reported `passed`. A Runner that crashes or closes its IPC channel marks its unfinished jobs `infrastructure_error`; a gateway restart marks them `interrupted`, and neither replays a test. Finished job records are removed after 14 days, a stopped run's output directory is removed with it, and one gateway serves a project.

`e2e list --reporter json` and `ListResult` from `e2e/runner` gain `projectRoot`, the absolute project root every pair's `file` is relative to.
