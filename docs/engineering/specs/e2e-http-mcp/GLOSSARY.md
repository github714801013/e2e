# HTTP MCP 测试服务术语

本词汇表区分测试执行、认证复用和客户端探索中的概念，避免将不同生命周期的会话混为一谈。

## 术语

**Run（运行）**：同一项目、环境、站点 Origin 和账号下的一次有限测试执行周期，可包含多个作业。
_避免_：客户端会话、浏览器会话。

**Job（作业）**：调用方一次提交后可独立查询状态和结果的测试请求；多个作业可以属于同一次 Run。
_避免_：Run、单条测试。

**RunKey（运行归属键）**：项目、环境、完整站点 Origin 和账号的组合，用于判断请求是否属于同一活动 Run。
_避免_：域名、HTTP MCP 会话 ID。

**认证快照**：登录成功后保存的认证状态，供同一次 Run 内不同测试的独立浏览器上下文复用。
_避免_：共享浏览器、跨 Run 登录持久化。

**HTTP MCP 会话**：一个已认证客户端与测试服务之间的协议会话，具有独立的归属和生命周期。
_避免_：认证快照、探索浏览器会话。

**探索浏览器会话**：通过原生 open_session 工具开启、供客户端交互探索的浏览器使用周期。
_避免_：Run、Runner SessionStore。

**封口**：活动 Run 永久停止接收新增作业的时刻；之后到达的请求等待后继 Run。
_避免_：临时暂停、作业取消。

**并发上限**：由服务端规定的同一次 Run 同时执行测试的最大 Worker 数量，客户端作业不单独指定该值。
_避免_：客户端 workers 参数、常驻 Worker 数量。
